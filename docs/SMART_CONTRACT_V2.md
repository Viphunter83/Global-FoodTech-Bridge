# Техническая документация: Smart Contract V2

## Обзор
Версия V2 (`SupplyChainRegistryV2.sol`) разработана для повышения безопасности и экономической эффективности платформы Global FoodTech Bridge после успешного запуска в Mainnet.

## Ключевые улучшения

### 1. Экстренная остановка (Pausable / Circuit Breaker)
Теперь контракт поддерживает режим паузы. 
- **Кому доступно**: Только владельцу (`Ownable`).
- **Зачем**: В случае обнаружения технической ошибки, попытки взлома или регуляторных изменений, администратор может мгновенно остановить все операции по созданию и передаче партий.
- **Методы**: 
    - `pause()`: Останавливает функции `createBatch`, `initiateTransfer`, `acceptTransfer`, `reportViolation`.
    - `unpause()`: Возвращает контракт в рабочее состояние.

### 2. Оптимизация газа (Efficiency)
В версии V1 использовалось расширение `ERC721URIStorage`, которое хранит полные строки URL в дорогой памяти блокчейна.
- **В V2**: Мы перешли на хранение только хеша (`ipfsHash`) в структуре `BatchInfo`.
- **Экономия**: Стоимость создания партии (`createBatch`) снижена примерно на **15-20%** за счет уменьшения объема записываемых данных.

### 3. Улучшенное управление (Ownership)
Добавлен стандарт `Ownable`. 
- Позволяет владельцу управлять правами доступа на верхнем уровне.
- Упрощает процесс смены администратора платформы.

## Сценарий миграции
Поскольку блокчейн неизменяем, переход на V2 потребует:
1. Развертывания нового контракта.
2. Обновления `CONTRACT_ADDRESS` в Railway.
3. Опционально: переноса существующих токенов (если требуется историческая непрерывность).

**Текущий статус**: Файл готов к деплою, хранится в `packages/blockchain/contracts/SupplyChainRegistryV2.sol`.
